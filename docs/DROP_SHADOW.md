# Bounded portable drop shadows

`cui_set_drop_shadows` copies up to eight caller-owned layers onto the open box. They paint in supplied order before its background and before its child-overflow clip, under the current ancestor mask and opacity. `count=0` clears the list. Shadow pixels add no interaction or semantics. A layer contains logical pixel offset, signed spread, Gaussian standard deviation (`sigma`), and straight RGBA8 color. Original caster corner radii clamp against the original dimensions; spread changes bounds without changing those radii. Negative spread that collapses either dimension succeeds as empty paint.

`cui_prepaint_drop_shadow` emits the same value-owned primitive. It consumes one command per layer plus existing clip wrappers. Deferred paint inherits existing viewport/modal rules and ancestor opacity exactly once. It never borrows a caller layer list or performs layout, semantics, interaction, or invalidation. Existing component/prepaint emission rollback applies; renderer preparation, external callbacks and later device submission have their existing separate failure boundaries.

`cui_theme_popover_shadows(theme,strength,out)` copies the source popover's three layers: foreground at alpha `.1`, zero offset/sigma, spread `+1`; black alpha `.1`, offset `(0,4)`, sigma `3`, spread `-1`; black alpha `.1`, offset `(0,2)`, sigma `2`, spread `-2`. Finite strength clamps to `[0,1]`; output is unchanged on invalid input. Theme projection is consumed by both styled Chart tooltip composition and current-frame paint. `NULL` tooltip style retains its legacy behavior; bare style paints neither surface nor shadows. Projected boxed style has three copied layers. `ring_color` overrides every canonical sigma-zero, spread-one, zero-offset ring; non-ring custom layers use their own color. Explicit style with zero layers retains its previous sigma-zero ring fallback. All layer values are copied into deferred payloads, including when caller options/style are destroyed or relocated.

## Kernel and supported domain

`cui_effect_drop_shadow_query`, `sample`, and `raster` use the pinned GPUI 0.3.8 f32 renderer model: rational erf for the horizontal Gaussian integral, four vertical midpoint samples, and finite three-sigma support. Sigma zero fills the rounded SDF shape with a one-physical-pixel coverage ramp beneath translucent surfaces. This differs from CUI's existing separable **box** blur. It also differs from an infinite exact mathematical Gaussian convolution; the pinned shader itself is a bounded four-sample approximation.

Query/raster accept an explicit uniform logical-to-physical scale and physical origin. Scale is `[1/65536,64]`. Caster coordinates/dimensions and radii are finite and bounded to 16384; offsets/spread to absolute 4096; sigma is `[0,256]`. To prevent f32 underflow/division from publishing NaN coverage, positive physical sigma below `4*sqrt(FLT_MIN)` is rejected atomically; sigma zero is a separate supported case. Raster dimensions are at most 16384 per side and 16 million pixels. Invalid/capacity failures leave published query/sample output and caller raster storage unchanged. Raster uses caller storage and performs no allocation.

Query `covered_layer` reports the physical integer covered unblurred layer bounds, from the same checked calculation that supplies raster geometry. The bounded scale/origin/caster domain keeps these integer edges exactly representable as floats. Physical covering floors near edges and ceils far edges. Supplied radii retain their original caster clamp through spread. Scene culling mirrors the pinned source: it tests the **unblurred** covered layer bounds against the current covered mask; a tail-only intersection paints nothing. Prepared masks crop to covered physical near/far bounds. Source pixel-grid covering can intentionally expose a full boundary pixel beyond a fractional logical mask; generic logical clip rounding or Canvas clip antialiasing must not replace that rule.

## Adapter preparation and budgets

All native adapters prepare shadow pixels/resources before clearing/submitting target paint. Software coordinates already represent physical pixels and use scale 1. SDL Renderer derives actual render scale, viewport origin and logical presentation rectangle; SDL GPU derives acquired drawable/list projection; Sokol derives physical target/list projection. Canvas uses the actual `ctx.getTransform()` scale/origin, rather than backing-store/list ratios that include canvas-dimension rounding. A shadow frame with genuinely nonuniform or unsupported transform fails before clear; frames without shadows preserve their existing transform behavior. Uniformity tolerance is four float ULPs relative to the larger positive scale.

Each native adapter owns a bounded 64-entry coverage cache. CPU shadow storage is at most 32 MiB and uploaded shadow images at most 32 MiB, for at most 64 MiB owned cached pixel storage. Public raster query's 16M pixel limit is independent: a raster too large for an adapter's available cache fails explicitly. Frame-used entries cannot be evicted by later preparation. Integer device translations and opacity changes reuse coverage; fractional phase, dimensions, sigma/spread/radii, scale and colors distinguish entries. Actual covered dimensions/position are checked before normalized translation reuse, including large-coordinate f32 cancellation. Resource creation never holds a caller stack pointer. Transient frame command copies, upload staging, C raster caller buffers and graphics-driver overhead are separately bounded by their existing/declared budgets, not included in cached pixel accounting.

SDL Renderer suspends its rounded logical clip while painting a prepared, physically cropped shadow, then restores it; target viewport remains active. SDL GPU shadow scissors use actual target bounds and prepared physical crop. Ordinary draws keep their existing clip path. On predictable GPU preflight failure no swapchain is acquired. The separate lifecycle hotfix handles unavoidable post-acquisition resize races legally: it submits a blit of the previous completed offscreen surface when available. It never cancels an acquired swapchain. A first frame without a previous surface and device submission failure cannot promise unchanged presentation.

## Canvas host wiring

`web/modules/cui_shadow.js` exports `createCuiShadowRenderer` and `cuiShadowWasmRasterizer`. `web/modules/cui_shadow_bridge.c` is the standalone bridge/example schema for the existing pure C kernel; it is not automatically linked into applications. The gallery links this bridge, copies each shadow value command, preflights all rasters before either resizing or clearing its Canvas, and suspends ordinary fractional clips while drawing the prepared physical masks.

The host decodes commands to `{type:'shadow',values:[caster x,y,w,h; original radii TL,TR,BL,BR; offset x,y,sigma,spread; R,G,B,A]}`, clip commands to `{type:'clipPush',bounds:[x,y,w,h]}`/`{type:'clipPop'}`, and other commands to `{type:'other'}`. All 16 values are copied. Call `renderer.prepare(commands,ctx,logicalWidth,logicalHeight)` **before** clearing the target; errors leave target pixels unchanged. The checked C query and raster provider returns copied metadata and borrowed pixels used only synchronously during preparation. WASM memory views are recreated after each call to tolerate memory growth.

At each shadow command, suspend the host's generic Canvas clip stack, call `prepared.draw(index,ctx,{unclipped:true})`, then reapply that stack for subsequent ordinary commands. Prepared physical mask cropping owns shadow clipping; inherited `ctx.clip()` would antialias fractional boundaries incorrectly. The explicit flag documents this host responsibility; Canvas cannot inspect or reset an arbitrary caller clip stack itself. Prepared frames expire on the next `prepare` or `clear`; expired draws reject, and their retained pixel references are released even if a host keeps the old frame object. `draw` rejects transform changes after preparation. It performs no clear. Ordinary commands remain the host's responsibility and preserve their paint order. Cache clear/destruction releases module-owned references; Canvas/browser/driver resource retirement is managed by the browser.

Bridge exports are `cui_canvas_shadow_values` (pointer to16 writable floats), `cui_canvas_shadow_query`, `cui_canvas_shadow_prepare`, `cui_canvas_shadow_width`, `cui_canvas_shadow_height`, `cui_canvas_shadow_bound(index)`, `cui_canvas_shadow_layer_bound(index)` (physical unblurred bounds), `cui_canvas_shadow_pixels`. Query/prepare return 0 on failure and 1 on success. Pixels are straight RGBA8; copied metadata bounds are logical placement, widths/heights physical raster dimensions. The bridge's single reusable raster buffer is borrowed until its next prepare call and capped to 32 MiB. The renderer copies it synchronously into an offscreen Canvas; caller stack buffers are never retained.

## Verification scope

Headless tests compare the pinned four-sample model against independent exact rectangle Gaussian CDF, and exercise symmetry/cutoff, sigma-zero corners, signed spread, subnormal rejection, finite cancellation, atomic output, copied layers, source order/opacity, child overflow, tail-only exclusion and bounded frame/cache failure. Actual native SDL Renderer/Vulkan/Sokol readback and Chromium WASM tests cover both physical scales 1/2 and all three layers beneath translucent surfaces. Existing appearance proof retains both consumers, automatic/copied content, bare behavior, line boxes, corner geometry, progress/ancestor opacity and stationary move/resize.

Exact pinned native Metal/WGPU shader antialiasing/color-format image identity is not certified by these portable kernel and adapter tests. Public inset shadows, arbitrary nonuniform transforms, renderer-specific color spaces, and native GPUI image captures remain outside this bounded drop-shadow slice. No full BoxShadow or Chart family completion is claimed.
