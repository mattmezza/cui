Use immutable shared `cui_selection_events.h` types and ACTIVATION reason. Missing handler preserves normal caller-owned selection mutation and reports zero callback invocations. No option/result layout is changed.

The Styled Select renderer currently constructs private list options and calls `cui_base_list`; that reducer processes the whole event batch before Select closes the popup. Add a private cross-translation-unit forwarding reducer (`cui_choice_private_list_events`, locally declared in Components, not a public application API). Its extra control ID/handler/result pointer observe each actual selection write, after the existing activation/confirmation callback sequence, with frozen pre-callback metadata and pre/post-operation values. Legacy `cui_base_list` calls that implementation with no observer. Only new Select forwarding enables the observer; List/Menu/Combobox/multi-select remain unchanged.

No entry/exit comparison can implement this: A→B→A must emit two transitions while Select retains false final `legacy_changed`. Same-item activation closes the popup without CHANGE. Callback updates to owner selection affect subsequent events and final legacy comparison, with no recursively synthesized event. Preserve full list pass, focus/typeahead/scroll logic, and popup close after the pass. No preflight or early semantic registration is added.

Attempt a genuine existing snapshot only if already available; never register early to obtain one. Otherwise freeze only actual frame/index/source from explicit pointer-up, key or accessibility event type and omit HAS_ACTIVATION. Handlers/payloads are synchronous borrowed views; pointer-free copies survive frame/context lifetime. Caller storage/resources/users remain alive through existing boundaries. No context destruction guard, recursive submission, queue, retiming, request rejection, lifecycle/confirmation event, query observer or foreign hook is added. Tests must cover real pointer/touch/key/accessibility, multiple transitions returning to entry, handler owner writes/consuming later input, same-item close, disabled/inert/omission, scroll-invalidated pointer activation, legacy coexistence and explicit evidence absence.
