# Frozen initial integration contract
Core types in include/cui/cui.h; core implementation src/core/cui.c. Public C11, no Clay/platform types. All dimensions logical pixels. Width/height 0 fits contents, negative grows, positive fixed. Explicit begin/end element composition backed by Clay. Frame strings copied to context frame arena; draw-list/semantic pointers valid until next begin. Context fixed capacities reported by errors, no per-frame allocation. Single UI thread across contexts: Clay's current context is switched by adapter, not safe concurrent calls. Input events queue before begin, dispatched against previous frame regions in order; first frame has no targets. Controls consume per-ID activation exactly once. Focus is retained only for submitted enabled controls; cancellation clears capture. Stable scoped 64-bit IDs with debug duplicate detection; Clay uses a folded internal ID.
Renderer vtable consumes draw list synchronously; returns bool and reports actual backend/capabilities. Platform produces generic events and owns OS resources. Text measurement callback is independent, default approximate metrics explicitly documented. Base owns interactions; style wrappers call base and theme tokens. Worker changes to public contract require integrator coordination.

Ownership: core worker core header/source/tests; base/style worker base/theme/components and tests; graphics worker backends/text/gallery. Integrator build/scripts/docs/manifest. Workers use isolated git worktrees and commit scoped changes; no direct mainline edits.
