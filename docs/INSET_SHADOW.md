# Bounded inset shadows

`cui_set_box_shadows` copies up to eight total DROP and INSET layers onto the open box. It replaces the complete list. Zero count clears both phases; the existing drop-only setter also replaces the complete list, so it clears previous insets. Invalid kinds, counts, dimensions, radii or nonfinite values fail before changing the owner. Existing drop APIs and enum values retain their behavior.

```c
cui_box_shadow layers[] = {
    {.layer = {.offset_y = 2, .sigma = 3, .color = {0, 0, 0, 64}},
     .kind = CUI_BOX_SHADOW_DROP},
    {.layer = {.spread = 2, .sigma = 1, .color = {0, 0, 0, 96}},
     .kind = CUI_BOX_SHADOW_INSET}
};
/* Between begin_box and end_box. Failure leaves the previous list intact. */
bool ok = cui_set_box_shadows(ui, layers, 2, (cui_corner_radii){4, 4, 4, 4});
```

DROP layers paint before the background. INSET layers paint after the background, before local mesh/underlay/prepaint content and children. Supplied order survives within each phase. Both use ancestor opacity and the current ancestor mask, before the box's own child-overflow clip. Shadows create no interactions or semantics. The existing outline and ordinary content/border paths keep their prior ordering.

The source hole is the original caster offset by the layer, dilated by **negative** spread. Positive spread shrinks the hole. Original radii clamp against the original caster; hole radii are `max(original_clamped_radius - spread,0)`, with no second hole-size clamp. Materialized source f32 origin/size determine the far edge before physical floor/ceil covering. Even a logically collapsed hole can cover a physical pixel. Sigma-zero coverage uses the source SDF ramp and unrounded `max(qx,qy)` fast path. Gaussian coverage uses source erf/four-midpoint integration without a DROP support-rectangle cutoff. The result complements the raw hole convolution and multiplies independent element SDF coverage, then clamps/quantizes for straight RGBA8 storage.

Scene insertion/culling uses the **covered hole**. Rasterization and final cropping use the **covered element**, intersected with the covered ancestor mask and target. An empty or mask-disjoint hole suppresses the whole primitive even if the element overlaps. An intersecting hole can produce inset pixels in element regions outside that hole. This intentionally follows pinned gpui-pre 0.3.8 Scene behavior; it is not an unconditional mathematical complement for an empty hole.

`cui_effect_inset_shadow_query` returns logical raster placement, physical integer `covered_hole` and `covered_element`, and raster dimensions/bytes. The raster is the covered element, without Gaussian tail expansion. Query validates before publishing output. `cui_effect_inset_shadow_sample` evaluates a physical point and returns zero outside the element or for an intrinsically empty hole. These pure functions have no ancestor-mask input; mask-dependent insertion culling belongs to the prepared renderer. `cui_effect_inset_shadow_raster` validates the entire caller-owned buffer before writing. No pure operation allocates or retains caller pointers.

`CUI_DRAW_INSET_SHADOW` is appended; its `shadow` field stores the paint by value. `cui_prepaint_inset_shadow` emits this value into the existing bounded writer and supports deferred output. Count the emitted command and its clip wrappers in the callback's budget. The payload registration copies values; contained host pointers remain borrowed under the existing prepaint contract. Manual callbacks choose their own surface/layer order. They cannot call layout, semantics or Core mutation during prepaint.

The portable supported domain matches DROP: finite caster coordinates/dimensions up to16384 (dimensions nonnegative), absolute offset/spread up to4096, radii in[0,16384], sigma in[0,256]; uniform scale[1/65536,64], origin magnitude up to1048576. Positive physical sigma below `4*sqrt(FLT_MIN)` is explicitly rejected; sigma0 is separate. Raster sides are at most16384 and total raster area at most16M texels. Hole geometry is not charged as a raster allocation. DROP/INSET share the eight-layer limit,64 cache entries and combined64MiB owned CPU/upload budget. Unsupported nonuniform shadow transforms and resource failures reject before target resize/clear or swapchain acquisition. Frames without shadows keep their existing transform behavior. Existing late SDL GPU acquisition failures retain their legal-submit/previous-surface boundary.

Software uses existing physical coordinates. SDL Renderer derives actual presentation/scale/viewport; SDL GPU and Sokol derive actual target/list projection. All native paths preflight resources, then paint the prepared cropped physical bitmap without applying another rounded element clip. Cache keys distinguish kind, paint values, transform and f32 phase; alpha-only changes reuse coverage. Normalized translation reuse requires both hole and element geometry to agree with actual checked covering. All prepared resources remain pinned until their frame submission; an earlier prepared frame expires when preparing another frame.

Canvas's reusable module recognizes `type:'insetShadow'` alongside `'shadow'`, with the same sixteen copied paint values. Its rasterizer/query accept an optional fifth argument `kind` (0 DROP,1 INSET). Existing DROP calls remain unchanged. New C bridge exports are `cui_canvas_inset_shadow_query`, `cui_canvas_inset_shadow_prepare`, and `cui_canvas_inset_shadow_element_bound`. Existing layer-bound getter returns the covered hole for inset; existing raster getters return the covered-element raster. Prepare reads the actual `ctx.getTransform()` uniform scale/origin before backing-dimension assignment or clear. Draw requires ordinary Canvas clips suspended/restored because prepared crops own physical mask coverage. WASM pixels are copied into cache-owned images before subsequent bridge calls. Gallery serialization/export wiring belongs to the integrating host.

Headless proofs cover literal square inset pixels, asymmetric independent radii, source square SDF diagonal, element AA, Gaussian complement versus independent double rectangle convolution, beyond-hole support, fractional collapse, zero/invalid/small-sigma atomics, copied Core/prepaint values, mixed phase/translucent/ancestor composition, legacy clearing, hole-mask culling, cross-kind and translation cache reuse, and bounded cache-slot failure preserving pixels. Native integration probes preserve actual DROP compatibility and compare INSET pixels through SDL Renderer pre-Present readback, SDL GPU Vulkan and Sokol GL at scales1/2. Canvas WASM covers DPR1/2, literal pixels, Gaussian/asymmetric composition and rejection before clear. The inset source fixture pins exact dependency/file hashes.

This capability follows the pinned public inset contract within the declared portable domain. Native GPUI Metal/WGPU shader/target-format/Hsla/transcendental/AA image identity remains unverified. Named convenience shadow factories and unrelated component owners remain separate contracts; no full BoxShadow or Chart family completion is claimed.

Small uniform target scales retain the checked physical raster budgets. A normalized translation that exceeds the public caster domain falls back to the original validated paint and origin; it does not widen that domain. Shadow bitmap dimensions use the already checked physical raster rather than the ordinary logical bitmap size cap. The headless cache, actual SDL Renderer, and Canvas probes cover this fallback and rejected-frame preservation.

SDL Renderer draws prepared shadows in physical target coordinates and restores logical presentation, scale, viewport, and clip before subsequent commands. Real OpenGL and software readback fixtures cover the tiny-scale edge oracle and normal-scale ordinary drawing after shadow emission; this does not change ordinary command geometry at extreme SDL scales.
