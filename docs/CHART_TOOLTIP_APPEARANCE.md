# Opt-in Chart tooltip appearance

`cui_chart_options.tooltip_style` applies explicit typography, spacing, colors and boxed/bare placement to automatic and copied typed tooltip content. A NULL pointer preserves existing tooltip behavior, including the old border. Automatic opt-in content uses the same bounded copying row arena as typed content: 32 rows, 4096 aggregate bytes, 1024 bytes per string, valid UTF-8. The style is borrowed only during synchronous composition and copied by value into current-frame prepaint; the callback rebinds to its copied payload, so caller stack storage can disappear after `cui_chart` returns. Caller data, callback users and existing raster buffers retain their existing borrowed lifetimes.

```c
cui_theme theme = cui_theme_light();
cui_chart_tooltip_style tooltip;
float rem_pixels = 16; /* host's current rem projection */
/* GPUI's default inherited relative line height, resolved for compact text.
 * Supply the actual resolved value when the host overrides line height. */
float inherited_line_pixels = roundf(.75f * rem_pixels * 1.618034f);
if (cui_chart_tooltip_style_project(&theme, rem_pixels,
                                  inherited_line_pixels, &tooltip)) {
    options.tooltip_style = &tooltip;
    options.interaction_mode = CUI_PLOT_INTERACTION_CURRENT_FRAME;
    cui_chart(ui, chart_id, &state, &options, cui_string("Revenue"));
}
```

The checked projection sets compact font .75rem, vertical gap .25rem, label/value gap .75rem, swatch gap .375rem, swatch size and padding .5rem. Minimum width stays 150px and Chart cursor gap 8px. Background/foreground use Theme.popover/popover_foreground; CUI Theme.muted supplies the muted foreground role. Surface radius uses Theme.radius; swatch radius is half. The outside ring uses Theme.text (source foreground) RGB with alpha .1, quantized to 26/255; source projection replaces its inherited alpha. It is distinct from popover foreground. Transparent colors are intentional values. Font and line height must be positive; other dimensions may be zero. Enum and finite bounded dimensions, including minimum viable spacing, are validated before interaction/state mutation. Factory failure leaves output untouched.

The source's `text_xs` sets font size without changing inherited line height. Pinned gpui-pre 0.3.8 defaults to a font-relative 1.618034 line height and rounds its resolved pixel value; Component Root sets rem size to Theme.font_size. The factory takes a resolved inherited line height explicitly instead of assuming glyph height equals font size. Measured glyph widths determine fitting; inherited line boxes determine vertical rhythm, with measured glyphs centered inside those boxes. A row reserves max(line height,swatch size) when any row has a swatch. Plain rows among swatched rows keep the empty slot; transparent swatches also keep it. Gaps appear only between existing title/rows, including an empty-present title. Values share the right edge. Existing per-value color overrides remain authoritative.

BOXED (zero enum) uses the projected surface and midpoint cursor flips independently on both axes. BARE uses the full plot extent at its origin, removes padding/minimum/surface/cursor anchoring, stretches row value alignment to the plot edge, and preserves the tooltip's deferred fade. Crosshairs and marks stay local. BARE currently supports bounded single-line structured content: intrinsic width exceeding the plot width fails rather than inventing wrapping. Source arbitrary element wrapping remains a separate gap.

Explicit CURRENT_FRAME follows immutable current bounds and pointer visibility under stationary scroll/resize. A style alone does not change AUTO's existing manual-pointer contract. Explicit LEGACY continues to use retained origin/manual pointer information; it does not gain current-frame geometry. Legacy custom `tooltip_content`/`tooltip_measure` remains supported, receives the projected content box, and must apply the host child font/line height itself. Custom measured sizes must be finite/nonnegative/bounded. Without a custom measurement the legacy content height remains a bounded 48px fallback. Arbitrary layout callbacks are still rejected by CURRENT_FRAME.

Invalid style returns false before output or owner mutation. Legacy copied structured content and custom measurement are staged before layout/semantics. Oversized measured content fails without publishing owner state. Current-frame measurement/emission failure rolls back that owner's paint output and state, reporting Core layout error; layout clip commands can remain. Host callback/measurement side effects, motion frame requests, borrowed raster writes and later global end-frame failures remain outside the existing transaction scope. Clear a reported Core error before retrying corrected input.

Source popovers have an outside translucent foreground ring and two Gaussian shadow layers. The consumed `ring_color` paints a 1px outside rounded band before the surface in both boxed paths: bounds expanded 1px, radius+1px, stroke 1px. Legacy uses the existing Core outline contract; current-frame emits the equivalent bounded deferred paint command, without Core input/layout mutation. BARE emits neither ring nor surface. Headless tests prove geometry, order, role distinction and alpha through ancestor opacity; the WASM probe proves outside/inside pixel compositing, including clipped half-opacity owners. This establishes the bounded ring behavior, not exact native GPUI shader/antialias pixel identity. Gaussian sigma 3/2 falloff remains a rendering gap; there are no shadow fields or approximations. Arbitrary current-frame interactive layout, source wrapping and accepted mobile long-press delivery/prevention also remain incomplete. This API does not establish full Chart or native accessibility parity.
