# Chart appearance and hover

`cui_chart` suppresses new hovered data while the marks appear. Default styled appearance lasts one second with quartic-out reveal; hover becomes eligible when **linear time** reaches completion. An eased float sample that rounds to1 early does not release the gate. Existing `appear_duration` overrides the duration. Manual `reveal_enabled` uses the rendered caller-supplied progress as its completion contract; render the requested progress before composing the chart.

A pointer moved onto a valid datum during appearance is remembered in caller-owned state. It becomes eligible on completion without a second move event. Moving outside before completion or making the chart noninteractive cancels this pending hover. Restarting appearance supplies no live datum but preserves the previous tooltip/mark presentation through its existing exit fade; once that fade finishes it disappears completely. Disabled appearance and owner/Core reduced-motion completion permit hover immediately. Noninteractive charts still animate their marks.

Keep `cui_chart_state` zero initialized with caller-owned pixel storage and `hovered=SIZE_MAX`, as in the existing API. The appended private `appear_hover_pending` field needs no application updates. Pure `cui_chart_hit_test`/`cui_chart_update_hover` remain geometry helpers; the styled widget applies the gate. Borrowed data, callbacks and pixel lifetimes retain their existing requirements.

This fix follows pinned GPUI Kit/Base0.7.1 commit `87d10ae5e1299d1be18670a37570c5402f952e34`, `crates/base/src/plot/element.rs::prepaint`: appearance is resolved before live tooltip state; appearing plots supply no live datum to retained hover tracking. It does not add automatic current-frame layout/occlusion tracking. Chart pointer coordinates still use retained bounds, and no native screen-reader or OS long-press parity is claimed.

The native regression uses actual pointer events and checks tooltip title draw commands. It covers incomplete/completed reveal, early float rounding, stationary resume, restart fade retention, move-out cancellation, settled redraw, noninteractive appearance, disabled appearance, owner/Core reduced motion and explicit progress. The browser test uses the real WASM gallery and Chromium mouse input: hover is absent during appearance, resumes with a stationary pointer after completion, settles on exit and works immediately with reduced motion. Browser touch/OS long-press behavior is outside this test.
