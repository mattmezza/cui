# Charts

`cui_chart_render` rasterizes into caller-owned, straight-alpha RGBA8 pixels. Allocate at least `width * height * 4` bytes and keep the buffer alive through renderer completion. Call it before `cui_chart` each frame. Both functions are allocation-free. Set `logical_width` and `logical_height` to render at a higher pixel density than the chart's logical size; hit coordinates use logical size. A nonzero `data_revision` enables a cache: increment it whenever a datum, series, link, or fill callback's user data changes in place. Zero disables caching. State, input arrays, strings, and output pixels remain caller-owned.

The adapter covers seven chart families. Line and area accept natural, linear, and step-after curves and up to seven additional series; each extra series can select its own curve, stroke, and area/radar fill. Bars support top, bottom, left, and right alignment, including negative values. Two-stop base-to-tip gradients, a per-pixel bar fill callback for chart-aware gradients or patterns, uniform or individually controlled rounded corners, and explicit reveal progress are available; set `reduced_motion` to draw a complete bar immediately. `cui_chart_render_animated(ui, state, options)` drives all seven families from the core frame clock using the source one-second ease-out-quart timing, replays when `appear_key` changes, and honors `cui_reduced_motion(ui)`. `appear_duration` overrides one second, and `disable_appear` draws immediately. Direct `cui_chart_render` remains deterministic with caller-supplied progress. Their band geometry uses the source defaults for inner/outer padding (0.4/0.2) and a 30px maximum width; caller options can change padding, width cap, unfinished band count, minimum length, and value-label formatting. `cui_chart_bar_bounds` exposes the same geometry used by the raster and hover lookup. Pie supports donut radius, a default outer radius of 40% of pixel height, slice padding, and optional outside labels with leader lines. `cui_chart_pie_labels` computes caller-owned overlap-adjusted positions and omits slices below 0.5 degrees; label text fades in after 70% of the sweep. Candlesticks validate OHLC, scale the price domain to observed lows and highs, and use source-default 0.8 body width inside padded bands, with bullish/bearish colors. `cui_chart_candle_bounds` exposes wick/body geometry; `candle_body_ratio`, `max_bar_width`, and `pie_outer_radius` allow overrides. Sankey computes an acyclic graph's longest-path layers and proportional node/link widths, then uses six weighted bidirectional relaxation passes by default with collision resolution; `sankey_iterations` overrides the pass count; `cui_chart_sankey_layout` exposes the caller-owned node geometry and rejects cycles before changing output. `cui_chart_sankey_link_bounds` exposes per-end ribbon centers and widths after stable source/target sorting; each side fills its node height even for imbalanced flows. The raster draws source-style cubic ribbons with source-to-target color gradients, a 0.3 opacity, and a 1px minimum link width by default. Sankey node text is opt-in, matching the source builder default; rounded nodes, value labels, font size, and label gap are configurable. Radar accepts the same additional series, a pinned maximum/outer radius, translucent fill, and optional vertex dots around dimension spokes. The theme helper fills absent colors, and the styled adapter draws category/value labels, simple legends and hover values as CUI text over the bitmap. Candlestick hover shows direction-colored open, high, low, and close rows. Set `tooltip_content` to draw caller-defined CUI tooltip content for the hovered datum; it replaces the default title and rows and runs once while hovered. Numeric label and hover formatting callbacks write into bounded buffers. `cui_chart_hit_test` returns a point or slice, a radar dimension, or a Sankey node.

This remains partial against the pinned GPUI Kit source. The method audit below lists the remaining gaps in labels, fills, axes, Sankey options, and hover effects. Value-axis gutter size is fixed rather than measured from text. `cui_plot` remains available for independent scales, ticks, pan/zoom, and clipping.

## Frozen source method audit

This maps the public builders in the pinned GPUI Kit seven-chart sources to this C adapter. A C datum array replaces source `new`, `x`, `y`, `value`, and OHLC accessor closures. `cui_id` replaces `id`. Every family uses `noninteractive`, `cui_chart_render_animated`/`appear_key`/`disable_appear`, and `tooltip_content` for custom content; `tooltip_format` formats numeric rows. Source tooltip title, value, and value-color closures have no individual C equivalents: the custom content callback can draw them, but the default tooltip cannot be customized independently. Source hover transitions, crosshairs, and dot/halo emphasis are not implemented.

| Source family | Covered methods and behavior | Remaining methods or behavior |
| --- | --- | --- |
| Line | `stroke` → `series[0]`; `natural`/`linear`/`step_after` → `curve`; `dot` → `show_dots`; `grid`/`grid_dashed` → `hide_grid`/`grid_solid`; `grid_columns`, `reference_line(s)`, `tick_margin`, `x_tick_count`, `point_count`, `x_axis`, `y_axis`, `y_axis_label_placement`, `y_domain`, `y_tick_count`, `y_tick_format` → corresponding options; `name` → semantic name. | `y_padding` is fixed; value-axis gutter is fixed rather than measured. The source's animated crosshair, per-point halo, and hover dimming are absent. |
| Area | Line's axes, curves, point count, grid, reference, names, and tooltip controls; up to seven extra `y` series in `extra_series`. | `primary_fill` and each extra series `fill` override the derived solid fill; gradient/pattern Background fills are absent. Per-series stroke/curve are available in `cui_chart_series`. `y_padding` and measured gutter remain absent. |
| Bar | `alignment`, `band_count`, `band_tick_count`, `corner_radii`, `fill`, `fill_gradient`, `grid`, `grid_dashed`, `max_band_width`, `min_length`, `padding_inner`, `padding_outer`, `tick_margin`, `value_axis`, `value_tick_count`, and `value_tick_format` map to bar geometry, fill callback/two-stop gradient, and shared options. `label`/`label_color` map to `show_bar_values`/`bar_label_format`/`bar_label_color`. | Source's arbitrary Background object is represented as pixels. Per-datum label-color callback and dynamic value-axis gutter are absent; horizontal value-axis labels need fuller source placement. |

Link color defaults to a source-to-target gradient; an explicit link color overrides it. |

All seven source families expose `appear`, `appear_key`, `id`, and `interactive`; the shared mapping above applies to each. Source builder methods for category/value accessors map to caller-supplied `cui_chart_datum` fields rather than callback registration. The methods listed as missing remain partial despite the available chart type names.
