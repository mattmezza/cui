## Chart formatting versus arbitrary content

Public Line/Area/Bar/Candlestick/Radar tooltip_title/value/value_color/content builders are actual exposed contracts; Pie/Sankey expose tooltip_name/value with chart-specific values. `chart/mod.rs:289–383` uses private TooltipContent to implement precedence, not a public generic builder requirement. Custom content returns an arbitrary element and suppresses title/value/color formatters without removing chart marks or changing placement. A missing numeric row result suppresses the tooltip. Public Line tooltip_content documentation explicitly describes table-like layouts (line_chart.rs:160–175). Source closures are owned Rc, 'static; returned SharedString/elements own retained data.

CUI's newly copying typed builder supplies title and bounded rows in both consumers, including empty title presence, plain/mixed/transparent slots and value-color overrides. It is a CUI portable extension implementing those visible row behaviors, not the Rust private builder exported verbatim. Current CUI dimensions remain font11/radius4/padding8/row16/title18/swatch8 with muted label alpha .7 and ordinary border. Theme popover fields exist but Chart still projects existing colors/styles. Existing tooltip_content/measure supports arbitrary layout only in LEGACY; CURRENT_FRAME rejects layout callbacks. Source arbitrary-content parity therefore remains incomplete. Typed builder conflicts with legacy content/measure and replaces automatic formatting; callback strings are synchronously copied (32 rows, 4096 bytes, 1024 per string), user/data remain borrowed through frame.

## Mobile phase and prevention

`crates/base/src/plot/element.rs:164–201` selects mobile handling only on iOS/Android. LongPressEvent is accepted only in bubbling phase. Started ignores already-default-prevented events and unhovered hitboxes; accepted Started prevents default and uses start_position minus current bounds origin. Moved ignores inactive cursor, otherwise uses event.position minus bounds origin. Ended/Cancelled clears cursor. View notification occurs only when optional cursor changes. Ordinary finger down is not hover. Desktop re-derives hitbox visibility and local position each paint for stationary scroll/resize; visibility flips request a corrective frame.

CUI Base cui_plot_cursor_long_press already models accepted/prevented Started, tracked Moved and clearing End/Cancel with pure update.accepted/changed outputs. It is an explicit caller contract; it does not deliver or prevent host events. Styled Plot touch skips automatic mouse update, but current-frame paint path rejects touch and legacy host must supply tracking. Chart has no accepted-long-press channel. Core touch drag priority/pan are not equivalent to long-press acceptance, bubbling or default prevention. No CUI prepaint callback may mutate input/default prevention. Actual native iOS/Android event delivery remains unverified.

## Proposed bounded slices (approval required)

1. **Value-only tooltip appearance projection** first: append opt-in borrowed `const cui_chart_tooltip_style *tooltip_style` (NULL preserves legacy) with copied-by-value payload. Fields: explicit font_size,line_height,title_height,row_gap,label_value_gap,swatch_gap,swatch_size,padding,min_width,radius,cursor_gap and foreground/muted_foreground/background/ring colors; explicit boxed/bare enum with zero LEGACY, no magic zero-as-unset dimensions. Checked component-layer factory takes Theme plus caller design metrics, writes output only after finite nonnegative bounded validation. Both consumers share layout and colors. Source boxed/bare positioning must be tested together, not just fields. Gaussian shadow capability must be proposed to Core/adapters separately; no layered rectangle approximation advertised as exact shadow. Smallest fully deliverable component slice is theme color/radius plus validated explicit metrics and boxed/bare placement, with shadow explicitly pending. No Base→Theme dependency.

2. **Paint-only arbitrary content**: separate immutable info callback with bounded writer and explicit measured size. Suggested `bool (*tooltip_paint)(const cui_chart_tooltip_info *, const cui_chart_tooltip_paint_info *, cui_prepaint_writer *, void *)`, with paint info containing absolute content bounds, progress and copied style; separate synchronous pure `bool (*tooltip_size)(const cui_chart_tooltip_info *, cui_size *, void *)`. Conflict-check typed builder/content before mutation. Size callback output finite/bounded, copied; paint callback consumes immutable current snapshot and emits only bounded paint operations, no layout/input/semantics. Callback false rolls back owner emissions/state, host side effects outside rollback. Legacy arbitrary layout stays supported with documented separate behavior; paint content cannot claim arbitrary retained interactive element parity. Genuine arbitrary interactive content needs a Core staged layout/measure/prepaint composition contract, owned by integrator, not layout inside current prepaint.

3. **Accepted mobile long press**: Core-owned dispatch contract first: immutable contact identity, Started/Moved/Ended/Cancelled, start/current absolute positions, bubbling/default-prevented status, hitbox visibility; synchronous input-phase acceptance result requesting default prevention before ancestor pan. Chart/Plot owner copies accepted cursor and contact ID, active Moved tracks outside plot until lift/cancel, render gates by appearance/visibility. Do not smuggle prevention into writer. Explicit opt-in touch mode preserves existing mouse/manual contracts. Host caller-fed phase API is a useful portable seam but cannot substitute for real platform delivery proof.
