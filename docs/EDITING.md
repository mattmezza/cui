# Explicit UTF-8 editing model

`cui/cui_edit.h` exposes a persistent model independently of any styled Input. The application supplies and owns a NUL-terminated buffer and its capacity, including the terminator. Only the model may mutate that buffer while attached; external changes require destroying and recreating the model. Creation rejects missing termination, malformed UTF-8, embedded NUL, and line breaks in single-line mode. The handle owns its cursor, selection anchor, scratch storage, and optional bounded history. Destroying it leaves the application buffer intact.

All offsets are bytes at Unicode scalar boundaries. Selection endpoints may be reversed. Left/right move one scalar and, without extension, collapse an existing selection to its corresponding edge. Home/End move to LF-delimited line boundaries; document start/end are separate motions. Word previous/next skip punctuation and whitespace between word starts. Up/Down preserve a Unicode-scalar column across logical lines, including short intervening lines; in single-line inputs they move to start/end. Explicit selection, edits and nonvertical movements reset the preferred column. Insert replaces a selection, and deletion removes a complete scalar or the selection. UTF-8 validation rejects truncated sequences, overlong encodings, surrogate code points, out-of-range code points, stray continuation bytes, and embedded NUL. Valid CR/LF insertions are rejected with `CUI_EDIT_LINE_BREAK` in single-line mode. Rejected mutations leave text, cursor, selection, and history unchanged. An identical replacement changes the selection without adding history.

Storage is allocated at creation, with no allocations during editing. Scratch storage uses one buffer capacity. `history_bytes` bounds the combined snapshot payload and metadata; each snapshot costs `capacity + sizeof(snapshot metadata)`. Fewer than two fitting snapshots disables history. `max_history_steps` optionally limits retained edits, with zero using the byte budget alone. Undo and redo restore text and cursor/selection; new edits after undo discard redo. Full history evicts its oldest snapshot. This snapshot design trades memory for straightforward bounded behavior, so large document editors should use a specialized model. The handle itself and scratch storage are outside the history budget.

`cui_edit_get_state` reports length, cursor, anchor, undo/redo availability, multiline mode, and a 64-bit content revision. Actual mutations, undo, and redo advance revision; movement, selection, rejected edits, and identical replacements leave it unchanged. Revision wraps modulo 2^64. `cui_edit_get_text` returns a view into the application buffer.

`cui_edit_apply_events` processes frame events only when `cui_event_target` resolves to the supplied control ID. It applies text, scalar left/right movement, Ctrl/Alt+Left/Right word movement, Up/Down logical-line movement, Ctrl/Meta+Up/Down document movement, Home/End, Ctrl+Home/End, Backspace/Delete, Ctrl/Meta+A, and multiline Enter. Shift extends movement selections. Disabled input ignores events. Single-line Enter is left to the control's submit behavior. The helper reports the first rejected event while continuing later independent events. Ctrl/Meta+Z and Ctrl/Meta+Shift+Z perform undo/redo; Ctrl/Meta+Y also performs redo. Text events must contain a terminator within their 64-byte payload. Pointer placement, selection painting, clipboard ownership, and shaping belong to later adapters or controls.

Unicode scalars are not grapheme clusters: combining marks, emoji sequences, and regional indicators can be split by movement or deletion. Word classification uses fixed, locale-independent letter/combining ranges plus ASCII digits and underscores; it is not full Unicode UAX #29 segmentation. There is no bidi navigation, shaping or grapheme navigation in this model. Textarea supplies pixel-based navigation across wrapped visual lines and guards composing/preferred-character key events; the model alone does not supply a native IME bridge. This provides tested scalar editing primitives and bounded history; it does not claim full Input/Textarea/Editor parity. Optional integration with libgrapheme, ICU, or an IME adapter can extend the model without imposing a mandatory compiled dependency on the core.

Tests cover malformed UTF-8, scalar selection/deletion, aliasing insert sources, capacity rejection, history eviction and branching, revision changes, multiline boundaries, routed same-frame events across focus changes, malformed event payloads, and 15000 deterministic mixed Unicode edit operations under address and undefined-behavior sanitizers.


Composite inputs can set `delegate_up_down` so an enclosing command palette or combobox owns vertical list navigation. Combobox reserves Up/Down even while closed so an arrow can open its options. Ordinary Input keeps caret navigation, including in read-only mode; disabled inputs ignore it. This explicit delegation prevents the editor from consuming list-navigation keys.
