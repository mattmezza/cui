## Reconciled coverage

Checked whole-value acceptance, opt-in CR/LF removal, scalar password masking with staged resource preparation, focused host configuration, Pattern tokens and Number formatting are implemented. Format validity runs after the custom predicate; empty candidates bypass acceptance; old-invalid healing is preserved. Hard presentation preparation precedes predicates; replay bypasses normalization/acceptance/formatting. IME UPDATE remains an unformatted normalized provisional view and COMMIT records the formatted value once. CUI provisional preedit does not mutate the committed document, unlike the source marked-text implementation. This difference remains intentional and documented.

`base/state.rs:3520–3553,3996–4198,4220–4285,10538–10565` establishes normalization, validator→mask→regex short circuiting, old-valid rejection and setter behavior. Regex is still absent: a callback capable of using a regex is not the source compiled-regex API. Seed normalization is explicit in CUI helpers and opt-in options; source `default_value` normalizes according to builder state without formatting/validation (`1241–1249`). Builder order therefore remains a source contract rather than an automatic CUI model-construction behavior.

Number preserves grouping, fraction truncation without padding, identity with no separator, intermediate signs/dots and explicit unformatting. **Enabled NUL separator remains unsupported** because the inherited CUI text contract excludes embedded NUL. Number checked formatting rejects CR/LF separators. **Multiline formatting masks, inline-token formatting and multiple-selection formatting remain unsupported**, with atomic rejection; zero-format editing remains available. Pure helpers are not evidence of those unsupported composed paths.

## Ranked complete implementation slices

1. **Ordinary selection and horizontal wheel behavior.** Reuse model word/grapheme/selection primitives and actual text geometry; append caller-owned Input pointer state for word anchor and click sequence, bounded drag autoscroll scheduling. No new hidden document copies. Wheel uses actual viewport width/text extent, handles precise pixel and line deltas, consumes only changed offset, and must not have paint immediately snap a manually scrolled viewport back to the caret. Caret reveal is triggered by text/selection/focus transitions rather than every idle paint. Preserve CUI disabled selection blocking and readonly navigation. Source attaches wheel/pointer listeners unconditionally (`state.rs:4543–4560`); resolve actual disabled wheel dispatch with a pinned composed test before claiming equality or changing disabled wheel policy. Preserve masked whole-word privacy and source right-click selection policy for later menus. Meaningful tests: Unicode/emoji word doubleclick, tripleclick whole single line, reverse word drag, shift click, token-consumed press, blur-retained selection; real-font left/right edge wheel, nested ancestor propagation, no-change endpoint propagation and offscreen caret restoration. Run real CDP mouse/wheel and touch regression; no claim of native menus from this slice.

2. **Built-in clear/reveal/loading and typed event results.** Append zero-off clear/reveal/loading options and source modifier-bearing submitted/focus/blur result fields, with optional synchronous notification callback over a bounded caller-owned event array if multiple events need preservation. Exact once after adoption; rejected edits produce no Change; UI notifications are not guarded acceptance predicates. Child IDs derive from parent; child activation cannot replay text input, drop focus or expose secret bytes. Clear uses one checked replacement with secure/format preparation then resets scroll/refocus; rejected clear must not reset selection. Reveal uses staged current presentation before changing display/config; forced allocator/factory failure retains old masked mode/resources. Source Focus/Blur ordering must account for deferred menus and removed control; report disappearance only when an explicit lifecycle owner can observe it. Test actual child semantics, loading clear suppression, disabled/readonly, Enter shift/secondary, reset/rebind, one Undo and native/CDP secret lifetime.

3. **Portable default edit-command menu plus paste interception.** Proposed independent capability/action API: `cui_input_edit_capabilities(...)` and `cui_base_input_edit_action(..., cui_input_edit_action, ...)`, using checked mutation and shared clipboard denial. Caller-owned menu state stores model identity/revision, focus owner and generation, not borrowed document pointers. Validate again at execution; stale/missing/disabled targets reject, clipboard side effects explicitly external. Default right-up menu and custom content callback compose the same actions; editable-only paste hook returns PASS/CONSUMED/error over a synchronous borrowed text payload initially, with rich/asynchronous clipboard a separately declared unsupported extension. Do not implement context commands by synthetic mouse/key events. Test right press inside/outside selection, exact Cut/Copy/Paste/SelectAll capabilities including secret/readonly, empty clipboard, rejected cut copying first, consumed paste, stale model/rebind and actual browser menu keyboard/focus. Native menu availability stays host-specific.

4. **Regex acceptance with an explicit dialect/dependency decision.** Add an independent matcher after custom predicate and format validity, not a second generic predicate that changes order. Suggested portable contract: immutable caller-owned compiled object/view plus declared byte extent; `match(user,value,scratch,bool *matched)` returning success or hard error, with declared userdata and scratch extents in checked requests. All spans participate in alias guards; same-model mutation guarded; capacity/budget/unsupported errors never masquerade as false (which could trigger invalid-old healing). Runtime policy swap does not rewrite seed/history; empty and replay bypass matcher; UPDATE gates composed view, COMMIT once. A bounded C11 Thompson NFA supporting the actual ASCII story is useful only as an explicitly named subset and leaves full Rust Unicode regex unresolved. Full source equivalence requires a reviewed pinned optional provider/parser+Unicode data plan; no default Rust/POSIX dependency or user installation is proposed here. Tests must include unanchored/anchored search, Unicode classes/boundaries/case folding/flags and unsupported syntax, linear budget/capacity failures, ordered callback counts/old healing, formatting+secret resource faults, typed/paste/cut/delete/IME/replay. A story-only ASCII matcher cannot close this ledger item.

5. **All source content purposes and truthful host mappings.** Append independent Core enum ordinals, semantic metadata/role mapping and existing finalized owner/generation config; no Core→components dependency. Host capability query distinguishes metadata, SDL input hint, browser autocomplete and native autofill. Appended purposes alone do not constitute native autofill. Keep omitted purpose ordinary; readonly/disabled/no focus resets, input↔textarea generation changes cancel stale session, hidden/visible stays separate. Exhaustive45 table tests, invalid enums atomic, no document/history change, actual DOM autocomplete and supported pinned SDL hints; macOS-only native source mappings require actual macOS proof. Nonstandard source tokens must not be invented as browser standards.

Cursor scheduling is independently implementable with caller time, bounded epoch/state and finite absolute deadline using existing Core wake seam; stop on blur/window inactive/disabled, pause on input, no perpetual idle invalidation. Reduced-motion behavior is a deliberate CUI policy, not source evidence. Full numeric widget stepping/min/max/blur clamp (`state.rs:10521–10621`) remains a separate NumberInput family audit; formatting Number is not that widget.
