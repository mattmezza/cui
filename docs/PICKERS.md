# Date and time pickers

`cui_picker.h` provides Calendar, DatePicker and TimeField. Core date/time structures and base reducers contain no platform, theme or Clay dependencies. Styled wrappers add only common box/text/portal commands. Selected dates/times and retained navigation state are application-owned.

Calendar renders one to three actual month grids, with configurable first weekday, selected date/range, minimum/maximum endpoints, disabled predicate and whole-widget disabled state. The grid model exposes 42 consecutive cells including neighboring dates and zero cells at Gregorian year boundaries. The styled view leaves neighboring cells blank to avoid duplicated month semantics. Date IDs remain stable across navigation/reordering. Each day has its full ISO date semantic name, disabled/selected details, and a roving Tab stop. The model supports years 1 through 9999. An invalid initial date defaults deterministically to 2000-01-01; applications provide their own current date.

Month/year buttons navigate by one/twelve months. Arrow keys move one day or one week, Home/End move to weekday-aligned row boundaries, and Control/Meta with arrows moves months/years. Disabled candidates are skipped with a bounded 366-attempt search. Navigation changes the displayed month when the cursor leaves the visible months. Enter/Space or a day pointer click selects the cursor/date. Range mode takes two activations, sorts reverse selections, and keeps a pending endpoint between frames; disabled predicates constrain endpoints, not every interior date. Navigation never implicitly changes selection. Styled cell size defaults to 32 logical pixels and is bounded to 20..128 pixels. Exact upstream locale labels, week numbers, today markers, hover-range previews, neighboring-day interaction and arbitrary month counts remain pending.

The base Calendar offers reduction and semantic submission separately, plus a combined convenience function. DatePicker uses this separation to close a selected popup before submitting its modal scope. Closing on selection, Escape, outside click or disabling restores a valid trigger focus; this avoids leaving a closed modal scope in the activation frame. It uses the same `cui_overlay` focus/dismissal state and `cui_popup_place` collision model as choice popups. Its actual calendar renders as a viewport portal beyond ancestor clips, flips/clamps to the supplied viewport, and confines Tab focus while open. Range pickers close only after the second endpoint. Trigger semantics report expanded/controls. The current appearance uses ISO labels, a selectable calendar, and placeholder text; editable date masks, clear controls, custom locale/date formats and preset ranges remain pending. Small viewports clip a calendar rather than resize or scroll it.

TimeField stores a valid 24-hour `cui_time` and displays segmented hours/minutes, optional seconds and optional AM/PM. Each segment has a name, numeric value/range and readonly/parent details; one active segment participates in Tab navigation. Left/Right changes segments, Up/Down wraps the active unit, Home/End selects its limits, and digit input advances after two digits. Two-digit drafts persist across frames. AM/PM accepts A/P or keyboard toggling. Twelve-hour display preserves the 24-hour model. Disabled/readonly suppress mutations. Strict standalone parse/format functions accept/emit ASCII `HH:MM[:SS]` and reject out-of-range units. Custom min/max times, typed separators, full-width normalization, configurable formats and native input/IME integration remain pending.

Meaningful tests exercise leap years and weekday grids over forty years, minimum/maximum/disabled dates, actual routed multiple-arrow navigation, weekend skipping, year controls, reverse range selection, all four themes, persistent segmented digits, hour/minute rollover, 12-hour periods and disabled/readonly behavior. DatePicker tests cover actual portal geometry outside a clipped parent, selection close with trigger focus restored in the same frame, seventeen trapped Tab events, Escape and outside dismissal. The same Calendar/TimeField event suite compiles with `CUI_PICKER_BASE_ONLY`, no theme/components linkage, and bare geometry; base drawing remains empty. Strict warnings, fully instrumented ASan/UBSan, and existing CTest pass before submission. Root owns build/distribution registration.
