# Product
## Platform
Native desktop C UI; portable architecture for additional targets.
## Stack
User supplied: C11, Clay, optional SDL3 and independent GPU adapters.
## Users
C application developers composing native interfaces and custom design systems.
## Product Purpose
A small embeddable UI core, reusable unstyled behavior and themed components.
## Capabilities and Constraints
Full 78-entry GPUI Kit 0.7.1 functional inventory is the long-term target. Real tested partial progress must be distinguished from parity. Primary development target Arch Linux Xorg.
## Brand Commitments
Original CUI visual identity; no copied GPUI branding.
## Evidence on Hand
Initial user brief. No existing framework or verified performance figures.
## Product Principles
Behavior independent of presentation; explicit ownership; evidence-based platform claims.
## Accessibility & Inclusion
Keyboard interaction and semantic tree independent of rendering.
## Session defaults
User explicitly delegates ordinary decisions during unattended work. Assumption: gallery uses restrained native tool styling and direct code construction to prioritize working framework functionality.
